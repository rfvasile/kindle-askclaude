# Usage

Everything here happens in KOReader on the Kindle; the computer only answers in the background.

Open the Ask Claude menu:
- **On a passage:** select text and tap **Ask Claude…**
- **On the current page:** Tools → Ask Claude → Open Ask Claude menu, or assign *Ask Claude* (Reader section) to a gesture in Settings → Taps and gestures → Gesture manager

The menu has:
- **Buttons** from the enabled modules; some only appear when text is selected
- **Ask a question…** for anything else
- **Continue: “…” (n answers)** picks up your last conversation, named after its first question
- **History:** earlier questions about this book, grouped by conversation with follow-ups indented; ● marks the one *Continue* picks up. Open an entry to continue or delete it, or clear the whole history at the bottom of the list
- **Modules:** turn modules on or off, delete them, or tap *+ New module*, describe what you want, and Claude drafts it for you to add or discard

Buttons and *Ask a question…* start a new conversation; **Follow up…** under an answer continues it. Every conversation still sees your earlier questions about the book, so Claude remembers them until you delete them from History. The first question about a book sends the book to the computer, once. Answers take 10–40 seconds; tap the message to cancel.

Tools → Ask Claude also has:
- **Spoilers OK for this book:** Claude reads the whole book and the no-spoilers rule is off, for this book only. Useful for re-reads and non-fiction; switching starts a new conversation
- **Refresh menu from computer**, after editing modules on the computer
- **Re-send this book**, if the file changed
- **Test connection**
- **Computer:** the `user@address:port` to connect to
